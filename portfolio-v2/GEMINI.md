### Core Filter Rules
- **No generic AI copy**: Avoid clichés like "Next-Gen AI", "Revolutionize", "Seamless Synergy", "Unleash Potential". Use grounded, factual engineering metrics.
- **No fake statistics or phantom telemetry**: Every metric must reflect real architecture (e.g. 10+ YOE, distributed microservices, sub-50ms data pipelines).
- **No repetitive boilerplate comments**: Keep functional code clean; comments should explain architectural rationale, not echo variable names.

### Design Standards for Rabby Hasan Portfolio
- **Style Archetype**: Luxury Obsidian & Champagne Gold (`#07090e`, `#0d1017`, `#dfc898`, `#b89b5e`, `#E1E0CC`).
- **Typography Hierarchy**: Font heading `Outfit` / `Plus Jakarta Sans`, body `Plus Jakarta Sans`, monospace `JetBrains Mono` for architectural metadata.
- **Micro-Interactions**: Prismatic ambient lighting, interactive spiderweb constellation threads, frosted glassmorphism (`backdrop-blur-2xl bg-black/60 border border-white/10`).
- **Accessibility**: Strict 4.5:1 text contrast in both Dark and Light modes. Zero unreadable or grayed-out text.
